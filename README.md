# 📌 Project Overview

The **Employee Management System** is a menu-driven Python application developed using **Object-Oriented Programming (OOP)** concepts.

This project demonstrates how **Inheritance**, **Encapsulation**, **Method Overriding**, **Constructors**, **Getter Methods**, **Match-Case**, and **Menu Driven Programming** can be used together to create a simple employee management system.

The user can create different types of objects like **Employee**, **Manager**, and **Developer**, and later display their details.

# 🧠 OOP Concepts Used

| Concept | Description |
|----------|-------------|
| Class | Employee, Manager, Developer |
| Object | Objects created for every class |
| Constructor | `__init__()` |
| Inheritance | Employee → Manager/Developer |
| Inheritance | Manager & Developer inherit Employee |
| Encapsulation | Private variables (`__e_id`, `__salary`) |
| Getter Methods | `get_id()` & `get_salary()` |
| Method Overriding | `display()` method overridden in child classes |
| Match Case | Used for Menu Handling |
| Dynamic Object Creation | Objects created according to user choice |
